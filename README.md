# AUTOCART React + Tailwind website

## Requirements
- Install Node.js (LTS) from https://nodejs.org/ if it is not installed.
- Open this project folder in VS Code.

## Run the website on your computer
1. In VS Code, choose Terminal → New Terminal.
2. Run: `npm install`
3. Run: `npm run dev`
4. Open the local address Vite prints in the terminal (usually http://localhost:5173).

## Create the dist folder for delivery
1. In the terminal, run: `npm run build`
2. A `dist` folder will appear inside this project.
3. Give the contents of `dist` to the developer, or ZIP the `dist` folder if requested.

## Important
- This is a redesign starter based on the content and assets in the supplied AUTOCART website ZIP.
- Review every section, image, contact detail and link with the company before publishing.
- The current contact phone and email were taken from the supplied website.
- If the hosting server expects a particular folder structure or deployment path, confirm it with the developer before delivery.
